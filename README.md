# oop-lab2-date

Лабораторная работа №2 по ООП. Перегрузка функций и методов

## Класс Date
- 3 конструктора (по умолчанию, с параметрами, копирования)
- Статическое поле objectCount
- Деструктор с выводом информации

## Перегруженные операторы
### Унарные
- ++x (префиксный инкремент)
- x++ (постфиксный инкремент)
- --x (префиксный декремент)
- x-- (постфиксный декремент)

### Арифметическое присваивание
- +=, -=, *=, /=

### Бинарные
- +, -, *, /
- <, >, <=, >=, ==, !=

## Класс Event
Хранение расписания мероприятий с датой и днём недели
